## 安装

网站：https://www.paddlepaddle.org.cn/install/quick?docurl=/documentation/docs/zh/develop/install/pip/linux-pip.html

安装 GPU 版本：
```bash
python -m pip install paddlepaddle-gpu==3.3.0 -i https://www.paddlepaddle.org.cn/packages/stable/cu118/
```

安装 CPU 版本
```bash
python -m pip install paddlepaddle==3.3.0 -i https://www.paddlepaddle.org.cn/packages/stable/cu118/
```

如果是 **GPU版本** 需要注意自己的 `CUDA` 版本，不要过高即可，查看命令：

```bash
nvidia-smi 
```

当前电脑的 CUDA 版本为 12.0，所以下载 小于等于 12.0 版本的 `paddlepaddle` 即可：

```bash
python -m pip install paddlepaddle-gpu==3.1.0 -i https://www.paddlepaddle.org.cn/packages/stable/cu118/
```

检查是否安装成功：

```bash
python -c "import paddle; paddle.utils.run_check()"
```
